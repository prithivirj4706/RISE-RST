1 CRITICAL CIS-5.2.10 SSH hardening

SSH root login disabled failed. Observed: permitrootlogin yes

A leaked or brute-forced root credential grants full remote access with no separate privilege-escalation step and no attribution to a named user.

Evidence sshd -T

Remediation

3 HIGH CIS-3.5.1 Network exposure

Host firewall is active failed. Observed: -P FORWARD ACCEPT

Without a host firewall every listening service is reachable from any network the host is attached to, including services the operator does not know are running.

Evidence iptables -S
-P FORWARD ACCEPT
-P INPUT ACCEPT
-P OUTPUT ACCEPT
Remediation
sudo ufw enable   # or: sudo systemctl enable --now firewalld
evidence_ref: CIS-3.5.1
4 HIGH CIS-5.2.11 SSH hardening

SSH password authentication disabled failed. Observed: passwordauthentication yes

Password authentication exposes every account to online guessing. Key-based authentication removes that attack surface entirely.

Evidence sshd -T
passwordauthentication yes
Remediation
sudo sed -i 's/^#\?PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config && sudo sshd -t && sudo systemctl reload sshd
evidence_ref: CIS-5.2.11
5 HIGH CIS-5.3.4 Privilege escalation

sudoers contains no blanket NOPASSWD grant failed. Observed: /etc/sudoers.d: deploy ALL=(ALL) NOPASSWD: ALL

A NOPASSWD grant removes the re-authentication step, so any process running as that user -- including a hijacked shell -- becomes root without a credential.

Evidence cat /etc/sudoers
/etc/sudoers.d: deploy ALL=(ALL) NOPASSWD: ALL
Remediation
sudo visudo   # remove the NOPASSWD entries shown in the evidence, or scope them to specific commands
evidence_ref: CIS-5.3.4
6 HIGH CIS-6.1.10 Filesystem permissions

No world-writable files in sensitive system paths failed. Observed: /etc/world-writable-example

Any local user can replace the contents of a world-writable file in a system path, turning a routine execution into privilege escalation.

Evidence find /etc /usr/bin /usr/sbin /usr/local/bin -xdev -type f -perm -0002 -print
/etc/world-writable-example
Remediation
sudo chmod o-w <path>   # run per file listed in the evidence
evidence_ref: CIS-6.1.10
7 HIGH CIS-6.1.3 Filesystem permissions

/etc/shadow ownership and permissions are correct failed. Observed: /etc/shadow mode=0644 owner=root group=shadow

/etc/shadow holds password hashes. Any read access by a non-root user turns into offline cracking of every account on the host.

Evidence stat -c '%n %a %U %G' /etc/shadow
/etc/shadow mode=0644 owner=root group=shadow
Remediation
sudo chown root:shadow /etc/shadow && sudo chmod 640 /etc/shadow
evidence_ref: CIS-6.1.3
8 MEDIUM CIS-1.9 Patch management

Automatic security updates are enabled failed. Observed: APT::Periodic::Unattended-Upgrade "0";

Most host compromises use a vulnerability with a patch already shipped. Unapplied security updates are the gap being exploited.

Evidence cat /etc/apt/apt.conf.d/20auto-upgrades
APT::Periodic::Unattended-Upgrade "0";
Remediation
sudo apt-get install -y unattended-upgrades && sudo dpkg-reconfigure -plow unattended-upgrades
evidence_ref: CIS-1.9
9 MEDIUM CIS-3.2.1 Network exposure

No unexpected service listens on all interfaces failed. Observed: listening on all interfaces:

A service bound to 0.0.0.0 is reachable from every network the host touches. Binding to localhost limits the blast radius to the host.

Evidence ss -tulnH
listening on all interfaces:
tcp 0.0.0.0:8080
Remediation
Bind the service to 127.0.0.1 in its own configuration, or block the port: sudo ufw deny <port>
evidence_ref: CIS-3.2.1
10 MEDIUM CIS-5.4.1 Authentication policy

Minimum password length policy is set failed. Observed: /etc/login.defs: PASS_MIN_LEN 4

Without an enforced minimum length, a single short password on any account undermines every other control on the host.

Evidence cat /etc/login.defs
/etc/login.defs: PASS_MIN_LEN 4
/etc/login.defs: PASS_MAX_DAYS 99999
Remediation
sudo sed -i 's/^#\?\s*minlen.*/minlen = 14/' /etc/security/pwquality.conf
evidence_ref: CIS-5.4.1
